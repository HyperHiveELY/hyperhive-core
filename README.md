# HyperHive

HyperHive is a Hyperliquid trading application with owner-controlled wallets, signed risk policies, a paper trading engine and independently verifiable execution records. Live trading is disabled by default. HyperCore handles trading and customer token payments. The contract deployment target is Kinetiq Elysium, chain ID 99901.

The repository includes the dashboard, API, signer, worker, auditor, contracts and regression suites. Security reporting and the authority model are described in [SECURITY.md](SECURITY.md). [Third-party notices](third-party/NOTICES.md)
